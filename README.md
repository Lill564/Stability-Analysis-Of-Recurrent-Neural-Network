# Stability Analysis of Discrete-Time Recurrent Neural Networks (RNN)

## Описание проекта

Проект посвящен исследованию и математическому доказательству абсолютной и глобальной экспоненциальной устойчивости двухслойных рекуррентных нейронных сетей (RNN) с ненулевыми смещениями.

В основу работы положен математический аппарат из статьи:
> **N.E. Barabanov, D.V. Prokhorov** — *"Stability Analysis of Discrete-Time Recurrent Neural Networks"* (IEEE Transactions on Neural Networks, 2002).

Проект состоит из двух основных программных модулей на Python:
1. `learning.py` — Обучение 2-слойной RNN и эмпирический анализ динамики.
2. `stability_analysis.py` — Строгая математическая верификация устойчивости через LMI.

---

##  Архитектура и модули

### 1. Обучение (`learning.py`)
Модуль отвечает за обработку данных, обучение рекуррентной сети и первичную симуляцию её устойчивости.

* **Данные:** Используются климатические показатели из датасета `DailyDelhiClimateTest.csv` (средняя температура, влажность, давление).
* **Модель:** Двухслойная перекрёстно-связанная RNN с весовыми матрицами $W_1, W_2, V_{21}, V_{12}$, смещениями $b_1, b_2$ и функцией активации $\tanh(0.5x)$.
* **Обучение:** Алгоритм Backpropagation.
* **Поиск равновесия:** Моделирование свободной динамики системы при нулевом входном сигнале ($x = 0$) на протяжении 500 шагов.
* **Эмпирическая проверка:** Внесение шума в найденные состояния равновесия $(z_1, z_2)$ и проверка возвращения системы к устойчивому состоянию.

### 2. Математический анализ устойчивости (`stability_analysis.py`)
Модуль строго подтверждает абсолютную устойчивость обученной сети на основе результатов статьи Барабанова и Прохорова.

* **Сдвиг системы:** Вычисляются сдвиги аргументов активации $c_1, c_2$ относительно точки равновесия $(z_1, z_2)$, после чего система переносится в начало координат.
* **Секторные границы:** Расчет нижних ($N_1, N_2$) и верхних ($M_1, M_2$) секторных ограничений для функции $\eta(s) = \tanh(s + c) - \tanh(c)$, что снижает консервативность анализа.
* **Расширенное пространство состояний:** Формирование объединенных матриц системы $A, B, \Theta$.
* **Решение LMI:** С помощью библиотеки `cvxpy` и солвера `SCS` решаются матричные неравенства относительно блоков матрицы функции Ляпунова $H$ и диагональных матриц $\Gamma_1, \Gamma_2$.
* **Результат:** При нахождении допустимого решения (`OPTIMAL`) гарантируется **глобальная экспоненциальная устойчивость** нейросети.
